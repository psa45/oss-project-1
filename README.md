
# Vertical Shooter (S/W Engineering Project 1)

Python과 Pygame을 사용하여 제작한 종스크롤 슈팅 게임입니다.

플레이어 비행기를 좌우로 움직이고 총알을 발사하여 위에서 내려오는 적을 물리치는 게임입니다. 적을 처치하면 점수를 얻으며, 플레이어의 생명이 모두 소진되면 게임 오버가 됩니다.

## 실행 방법

- Python 3.10–3.13
- pygame 2.x

```bash
pip install pygame
python main.py
```

## 조작 방법

| 키 | 동작 |
|---|---|
| ← / → | 플레이어 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 게임 종료 |

## 구현한 기능

- [x] F1 플레이어 이동 — 방향키로 좌우 이동하며 화면 밖으로 나가지 않음
- [x] F2 총알 발사 — Space 키로 총알 발사 및 화면 밖으로 나간 총알 제거
- [x] F3 적 명중과 점수 — 총알과 적의 충돌을 확인하고 점수 증가
- [x] F4 피격과 게임 오버 — 적과 충돌하거나 적을 놓치면 생명 감소
- [x] F5 재시작과 최고 점수 — R 키로 재시작하고 최고 점수 저장 및 불러오기

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 실행, 이벤트 처리, 점수, 생명 및 게임 오버 |
| `entities.py` | Player, Bullet, Enemy 및 Background 클래스 |
| `settings.py` | 화면 크기, 속도, 색상 및 게임 설정 |
| `assets/` | 게임 이미지 및 리소스 |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |
| `.gitignore` | Git에서 제외할 파일 설정 |

## 최고 점수

최고 점수는 `highscore.txt` 파일에 저장됩니다. 게임을 종료한 후 다시 실행해도 최고 점수가 유지됩니다.
